How Offline Lists Work

1. Build the listCreate a Program List from a student's active assigned programs.
2. Download before leaving Wi‑FiCOMPASS stores the program HTML, targets, and behavior tracking buttons on the device.
3. Run offlinePrograms run in order and each saved session is placed in the local sync queue.
4. Sync laterWhen internet returns, Sync sends the queued sessions to the normal COMPASS session record.
