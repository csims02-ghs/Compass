# COMPASS V25 Locked DTI Chain Rule

Applies to all future new or upgraded instructional programs that use DTI chains.

1. Include a unique dropdown option labeled **IEP Chain** immediately after **Short**.
2. Use exactly **T,T,T,T,T** (five target steps, zero distractors). One complete chain is one run.
3. Use the Body Parts V25 preview: separate blue T tiles and amber D tiles, with the same padding, borders, typography, and spacing.
4. Resolve any internal option key to the five actual T steps when Run Program begins. A display-only option fails QA.
5. Preserve all existing options and defaults, targets, benchmarks, historical data, and student assignments.
6. Preserve individual T-step scoring, student-assignment Save Setup, authenticated completion, IEP goal linking, behavior tracking, and Next Program gating.
7. Mastery continues to require the configured percentage and distinct instructional dates. Five steps on one date are not five dates. Benchmark probes are separate.
8. Test dropdown ordering, preview, five-step scoring, save and reload, persistence, navigation, layout, and historical data before claiming live completion.

**Visual reference:** Body Parts V25.
**Working example:** Clothing V25.7.
**Machine-readable reference:** COMPASS_PAGE2_STANDARD.rules.iepChain.

Do not automatically alter live programs just because the standard exists; apply and verify when each program is upgraded.
